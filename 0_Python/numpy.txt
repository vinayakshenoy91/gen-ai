If you access the built-in documentation for the functions, you will notice that most 
numpy functions take an optional parameter dtype. In addition to float, NumPy has several 
other data types such as int, and char

Autofilled arrays:
-------------------

# Return a new array of shape 3 with random numbers between 0 and 1.

print(rand_arr)

# Return a new array of shape 3, without initializing entries.
